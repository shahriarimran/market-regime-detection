# Milestone 1 — USD/TRY Market Regime Detection

## Overview

Milestone 1 develops and validates an **unsupervised machine-learning system for identifying market regimes in USD/TRY**.

The objective is not to predict the exact future exchange rate or directly generate BUY/SELL signals. Instead, the model answers a different question:

> **What type of market environment is USD/TRY currently experiencing?**

The final system classifies the market into three latent regimes:

| Code              | Regime                         | Interpretation                                                               |
| ----------------- | ------------------------------ | ---------------------------------------------------------------------------- |
| `LOW_VOL`         | Low-Volatility Trend           | Relatively orderly, low-volatility exchange-rate movement                    |
| `ELEVATED_VOL`    | Elevated-Volatility Transition | Intermediate state characterized by increased volatility and transition risk |
| `HIGH_VOL_STRESS` | High-Volatility Stress         | Strong volatility, large movements, drawdowns, and market stress             |

A **3-state Gaussian Hidden Markov Model (HMM)** was ultimately selected after comparison against a K-Means baseline and extensive chronological validation.

---

# 1. Economic Motivation

Financial markets do not behave according to one constant statistical process.

Periods of relatively orderly trading can be interrupted by:

* monetary-policy shocks;
* inflation surprises;
* political uncertainty;
* liquidity events;
* capital-flow changes;
* currency crises;
* abrupt repricing;
* intervention or policy regime changes.

For USD/TRY, this is particularly important because the exchange rate has experienced both long periods of gradual depreciation and shorter episodes of extreme movement.

A model that assumes the same return and volatility characteristics at every point in time can therefore be misleading.

The regime-detection approach assumes instead that observed market behavior is generated by a smaller number of underlying **latent market states**.

Conceptually:

```text
Observed USD/TRY data
        ↓
Returns
Volatility
Trend
Drawdown
        ↓
Unobserved market condition
        ↓
LOW VOLATILITY
ELEVATED VOLATILITY
HIGH-VOLATILITY STRESS
```

The regime itself is not directly observed. It must be inferred from market behavior.

# 2. Dataset

The underlying USD/TRY history covers approximately:

```text
2017 → 2026
```

The original source contained inconsistent weekend observations across different historical periods.

For machine-learning purposes, the data was standardized to **Monday–Friday observations only**.

Weekend values were removed rather than synthetically forward-filled because artificial weekend observations would introduce zero returns and distort:

* rolling volatility;
* momentum;
* moving averages;
* drawdown calculations.

After preprocessing:

```text
Raw weekday observations:      2,505
Feature-complete observations: 2,445
Feature period:
2017-03-27 → 2026-08-07
```

---

# 3. Feature Engineering

The model does not use the raw USD/TRY exchange rate alone.

Instead, each observation is represented by eight features describing different dimensions of market behavior.

## Return Features

### `Return_1D`

One-day percentage return.

Measures very short-term exchange-rate movement.

### `Return_5D`

Five-day percentage return.

Provides a short-term momentum indicator while reducing some of the noise contained in daily changes.

---

# 4. Volatility Features

### `Volatility_5D`

Rolling standard deviation of daily returns over five observations.

Represents short-term volatility.

### `Volatility_20D`

Rolling standard deviation over approximately one trading month.

This became one of the most important features for economically interpreting the HMM states.

### `Volatility_60D`

Longer-horizon volatility measure.

Allows the model to distinguish temporary spikes from sustained turbulent environments.

The three volatility horizons collectively describe the **term structure of realized volatility**.

---

# 5. Trend Features

### `MA_Distance_20D`

Difference between the current exchange rate and its 20-day moving average:

```text
USDTRY / MA20 - 1
```

Positive values indicate that USD/TRY is trading above its recent average.

### `MA_Slope_20D`

Measures the recent slope of the 20-day moving average.

This represents the strength of the underlying exchange-rate trend rather than only today's price movement.

---

# 6. Drawdown Feature

### `Drawdown_60D`

Measures the exchange rate relative to its highest level during the previous 60 observations.

Conceptually:

```text
Current Price
───────────── - 1
60-Day High
```

A value near zero means USD/TRY is close to a recent high.

A strongly negative value indicates a significant correction from that high.

Drawdown is useful because two periods can have similar volatility but very different positions relative to their recent peaks.

---

# 7. Exploratory Data Analysis

Before modeling, the feature set was checked for:

* missing values;
* infinite values;
* unusual distributions;
* strong correlations;
* redundant information.

Several highly correlated features were removed.

In particular, the original feature set contained substantial redundancy among:

```text
Return_20D
MA_Distance_20D
MA_Distance_50D
MA_Slope_20D
```

The final eight-feature set was chosen to retain information about:

```text
Direction
+
Momentum
+
Short/medium/long volatility
+
Trend
+
Drawdown
```

without unnecessarily giving correlated trends excessive weight.

# 8. K-Means Baseline

K-Means was used as the first unsupervised benchmark.

Models with:

```text
K = 2, 3, 4, 5, 6
```

were evaluated using:

* Silhouette Score;
* Davies–Bouldin Index;
* cluster sizes;
* economic interpretability.

A three-cluster solution was selected for interpretation.

The K-Means model identified states resembling:

```text
Baseline Trend
High-Volatility Uptrend
High-Volatility Correction
```

K-Means produced relatively strong geometric clustering.

For the three-cluster model:

```text
Silhouette Score ≈ 0.566
```

However, approximately **87% of observations belonged to one baseline cluster**.

This suggested that K-Means primarily separated unusual market events from a large general-purpose normal state.

---

# 9. Why K-Means Was Not Enough

K-Means treats every observation independently.

It effectively asks:

> Which cluster centroid is today's feature vector closest to?

It does not know whether yesterday was classified as the same market regime.

Consequently, its classifications can switch rapidly:

```text
Baseline
Correction
Baseline
Correction
Baseline
```

Such behavior is undesirable for a regime-detection system because an economic regime should normally possess some degree of persistence.

The K-Means analysis therefore served as the static clustering benchmark rather than the final model.

---

# 10. Gaussian Hidden Markov Model

A **Gaussian Hidden Markov Model** was introduced to model temporal dependence explicitly.

The HMM assumes that:

1. the market occupies an unobserved latent state;
2. each state produces a characteristic distribution of financial features;
3. the probability of today's state depends partly on yesterday's state.

Conceptually:

```text
Previous Market State
          +
Current Market Features
          ↓
Probability of Current State
```

A three-state diagonal-covariance Gaussian HMM was fitted using multiple random initializations.

The best likelihood solution was retained to reduce sensitivity to local optima during expectation-maximization fitting.

---

# 11. Final HMM Regimes

The final full-history model identified the following state profiles.

## Low-Volatility Trend

Typical characteristics:

```text
5-Day Return:         ~0.34%
20-Day Volatility:    ~0.14%
20-Day MA Slope:      ~1.29%
60-Day Drawdown:      ~-0.04%
```

This state represents relatively orderly market movement.

It does **not** mean that USD/TRY is necessarily flat.

A currency can appreciate substantially over a long period while remaining in a low-volatility trend if the movement occurs gradually.

---

## Elevated-Volatility Transition

Typical characteristics:

```text
5-Day Return:         ~0.43%
20-Day Volatility:    ~0.65%
20-Day MA Slope:      ~1.56%
60-Day Drawdown:      ~-2.62%
```

This state acts as an intermediate environment between quiet and severely stressed conditions.

It is especially important because the HMM learned that transitions between low- and high-volatility states generally occur through this intermediate state.

---

## High-Volatility Stress

Typical characteristics:

```text
5-Day Return:         ~1.53%
20-Day Volatility:    ~2.01%
20-Day MA Slope:      ~6.46%
60-Day Drawdown:      ~-7.74%
```

This state captures periods characterized by large exchange-rate movements and substantially elevated realized volatility.

It includes major turbulent USD/TRY episodes without forcing the state to represent only upward or downward movements.

For that reason, `High-Volatility Stress` is preferable to labels such as `Uptrend` or `Correction`.

---

# 12. HMM Transition Structure

The HMM demonstrated strong state persistence.

Approximate self-transition probabilities were:

```text
Low-Volatility Trend:          ~98%
Elevated-Volatility Transition ~97%
High-Volatility Stress:        ~95%
```

An important learned pattern was the near absence of direct transitions between:

```text
Low Volatility ↔ High-Volatility Stress
```

Instead, the predominant regime structure was:

```text
Low-Volatility Trend
        ↕
Elevated-Volatility Transition
        ↕
High-Volatility Stress
```

Economically, this suggests that changes in market stress generally develop through an intermediate environment rather than instantaneously shifting between the lowest and highest volatility states.

---

# 13. K-Means vs HMM

K-Means produced better geometric cluster separation.

For example:

```text
Silhouette

K-Means ≈ 0.566
HMM     ≈ 0.167
```

This is expected because K-Means explicitly optimizes geometric cluster compactness.

However, the HMM produced substantially better temporal regime behavior.

| Metric                  |           K-Means |           HMM |
| ----------------------- | ----------------: | ------------: |
| Median episode duration |                 3 |            14 |
| Mean self-transition    |            90.70% |        96.74% |
| State distribution      | Highly imbalanced | More balanced |
| Temporal dependence     |                No |           Yes |
| Posterior probabilities |                No |           Yes |

The HMM was therefore preferred for the actual regime-detection objective.

---

# 14. Chronological Validation

The model was not accepted based only on full-history fitting.

A chronological holdout was used:

```text
TRAIN
2017-03-27 → 2023-12-29

TEST
2024-01-01 → 2026-08-07
```

The scaler was fitted using training observations only.

The HMM was also fitted using training observations only.

Test observations were processed using **causal forward filtering**, meaning that classification on date `t` used only observations available through date `t`.

No future observations were used.

This avoids look-ahead leakage.

---

# 15. Walk-Forward Validation

A stronger expanding-window validation was then performed.

```text
Train through 2020 → Test 2021
Train through 2021 → Test 2022
Train through 2022 → Test 2023
Train through 2023 → Test 2024
Train through 2024 → Test 2025
Train through 2025 → Test 2026
```

Results included:

```text
Mean OOS confidence:           ~99.05%
Mean switch rate:               3.27%
Median annual episode length:  19 observations
```

Importantly, the **High-Volatility Stress** state appeared on unseen data in:

```text
2021
2022
2023
```

This provided evidence that the stress regime was not merely a retrospective artifact of full-history fitting.

---

# 16. State-Stability Validation

Because HMM state numbers are arbitrary and model parameters can move after retraining, the economic meaning of the states was tested across expanding training windows.

The following properties were examined:

* volatility ordering;
* centroid drift;
* distance from canonical regime profiles;
* within-model state separation;
* feature stability.

The expected volatility hierarchy:

```text
Low < Elevated < Stress
```

passed approximately:

```text
95.83% of ordering checks
```

The minimum standardized state separation observed across folds was:

```text
1.0175
```

while the mean minimum separation was:

```text
1.8574
```

The learned regimes also became substantially more stable after enough market history accumulated.

---

# 17. Final Model Selection

Seven project-specific engineering acceptance gates were defined.

The candidate HMM had to demonstrate:

1. greater median regime persistence than K-Means;
2. greater self-transition probability;
3. mean out-of-sample switch rate ≤ 5%;
4. median annual episode duration ≥ 5 observations;
5. stress detection on unseen data;
6. ≥ 90% state-ordering stability;
7. minimum standardized state separation ≥ 1.0.

Result:

```text
7 / 7 PASS
```

Final decision:

```text
SELECT 3-STATE GAUSSIAN HMM
```

These thresholds are project acceptance criteria rather than universal statistical laws.

# 21. Model Limitations

The system should not be interpreted as a trading oracle.

The HMM:

* does not forecast the exact exchange rate;
* does not directly predict investment returns;
* does not independently generate BUY/SELL orders;
* does not guarantee that a high-volatility state will continue;
* does not identify the economic cause of a regime;
* is dependent on the quality and representativeness of historical USD/TRY data.

The inferred regime describes the **statistical market environment**, not a guaranteed future direction.

For example:

```text
HIGH_VOL_STRESS
```

means that the current feature pattern resembles historically high-volatility USD/TRY conditions.

It does not mean:

```text
USD/TRY will definitely rise tomorrow.
```

# 22. Relationship to the Financial Tracker

The regime model is designed to become an additional decision-support layer for the existing low-frequency financial tracker.

Future architecture:

```text
Traditional tracker
BUY / SELL / HOLD
        +
HMM market regime
LOW / ELEVATED / STRESS
        ↓
Combined monitoring output
        ↓
Excel
Telegram
Dashboard
```

The rule-based investment signal and ML regime classification should remain conceptually separate.

For example:

```text
USD/TRY

Rule-Based Signal:
HOLD

Market Regime:
Low-Volatility Trend

Regime Confidence:
98.7%
```

The regime supplies context rather than replacing the investment strategy.
